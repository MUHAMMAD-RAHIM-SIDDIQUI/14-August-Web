# Azadi - 14 August Website

A website celebrating Pakistan's Independence Day on 14 August. It is a simple, festive web page built to mark the day with a clean design and a patriotic feel.

**Live Demo:** https://14-august-web.vercel.app/

## What it does

- **Celebrates 14 August** - A dedicated page for Pakistan Independence Day.
- **Clean, festive design** - Green and white theme with a simple, welcoming layout.
- **Responsive** - Looks good on desktop and mobile.

## Tech Stack

HTML5, CSS3, JavaScript

## Run it locally

Open `index.html` with Live Server in VS Code, or serve the folder with any static file server.
